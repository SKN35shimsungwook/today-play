# 🍻 오늘 뭐하고 놀래?

친구한테 링크 보내면, 친구가 **레트로 메뉴판**에서 오늘 놀 코스를 직접 주문하는 Streamlit 앱.

## 흐름

1. **첫 화면** — "오늘 놀 사람? 🙋" `콜! 🍻` / `핑계 대기 😩`
   - `핑계 대기` 버튼은 4번 도망간 뒤에야 잡힘 (마우스/터치)
   - 핑계(피곤해, 돈 없어, 내일 출근…)를 고를 때마다 반박 멘트 + 빨간 **[기각]** 도장
   - 핑계가 다 떨어지면 `...알았어 놀자 🥲` 버튼만 남음
2. **기본 정보** — 인원, 만날 시간(시간대 또는 ⏰ 직접 설정)
   - **집 가는 시간**: 버튼 또는 ⏰ 직접 설정. 11시 전을 고르면 놀리면서 더 늦은 시간으로 강제 변경
     (밤 11시 30분 → 새벽 12시 30분 → 1시 30분 → 3시 → 첫차 → 해 뜨는 거 보고)
   - 한 번 늦어지면 다시 이른 시간으로는 못 돌림 ("번복 불가!")
3. **코스 짜기** — 🍚 밥 / 🍺 술 / ☕ 카페 / 🎳 놀거리를 누르는 순서대로 1차·2차·3차…
   같은 것도 여러 번 가능 (2차 술 → 3차 술)
4. **차수별 메뉴판** — 탭별로 여러 개 선택, ✏️ 직접 추가, 🎲 아무거나
   - 술: 술 종류 + 안주(국물·튀김·구이볶음·전·마른안주·해산물)
   - 카페: 컨셉(감성·베이커리·디저트·보드게임·루프탑·조용한) 먼저 → 음료 탭 + 컨셉 전용 탭
5. **예산 & 계산** — 1인 예산, 더치페이/내가 쏨/네가 쏨/게임 진 사람이 쏨
6. **오늘의 주문서** — 영수증 스타일 결과 + `📋 카톡에 복사하기`

## 실행

```bash
git clone https://github.com/SKN35shimsungwook/today-play.git
cd today-play
pip install -r requirements.txt
streamlit run app.py
```

## 구조

| 파일 | 설명 |
| --- | --- |
| `app.py` | 화면/흐름 |
| `menu.py` | **메뉴판 데이터** (핑계, 메뉴, 놀리는 멘트 등) — 메뉴 추가/수정은 여기만 |
| `.streamlit/config.toml` | 레트로 테마 색상 |

- 단계: `steps()`가 고른 코스에 맞춰 페이지 목록을 만들고 `session_state.step`으로 이동
- 친구가 고른 값은 `p_`로 시작하는 위젯 key에 저장, 매 실행마다 다시 대입해서 페이지를 넘겨도 유지
- 카톡 복사 버튼: `st.components.v2` (클립보드 API → 막히면 `execCommand('copy')`로 대체)
